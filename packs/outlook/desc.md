# Outlook pack

A playbook for Outlook on the web. The pack adds no API calls because the web
client does not expose a simple cookie-authenticated mail API.

## What it helps with

- Search queries in the Outlook search box.
- Reading an open message and summarizing it.
- Finding attachment, OneDrive and SharePoint links.
- Drafting a message field by field.

## Safety

Draft and ask before sending. No deleting, moving or flagging without explicit
confirmation.

## Hosts

`outlook.office.com`, `outlook.office365.com` and `outlook.live.com`.
