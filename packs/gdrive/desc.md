# Google Drive pack

A playbook for Drive web: search, browse folders, open files and download them.

## What it helps with

- Finding files by name or type through the Drive search field.
- Walking a folder with snapshots.
- Downloading a file or a set of files into `FoxAgent/Drive/...`.
- Converting Docs, Sheets and Slides to a downloadable format.

## Safety

No deleting, moving, renaming, sharing or permission changes without explicit
confirmation. A bulk download is proposed with counts and sizes before it
starts.

## Hosts

`drive.google.com`.
